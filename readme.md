# bookbot

Telegram-бот записи клиентов для небольшого бизнеса: барбершопа, салона, клиники, учебного центра. клиент кнопками выбирает услугу, мастера, день и время. владелец получает каждую запись в чат с ботом и ведёт расписание командами.

> [!NOTE]
> это демо. бот не работает ни в одном настоящем бизнесе, все имена, услуги и цены выдуманы. его можно потрогать и посмотреть, как устроен код. перед запуском у реального заказчика бота нужно настроить под его бизнес и проверить казахские тексты с носителем языка.

бизнес описывает один TOML-файл. чтобы перенести бота в другой бизнес, правьте этот файл, код трогать не нужно.

Python, [aiogram](https://github.com/aiogram/aiogram) 3 и SQLite. демо с выдуманным барбершопом: [@chuh_barberdemo_bot](https://t.me/chuh_barberdemo_bot), отвечает, пока включён мой ноутбук.

## что умеет клиент

- записаться в одном сообщении, которое меняется на каждом шаге: услуга, мастер или «Любой свободный», календарь на 14 дней вперёд, свободное время, подтверждение
- ввести имя и телефон один раз, телефон можно отправить кнопкой «Отправить мой номер»
- получить напоминание за сутки с кнопками «Приду» и «Отменить запись» и ещё одно за два часа
- в «Мои записи» перенести или отменить визит
- посмотреть услуги с ценами, адрес и контакты
- написать администратору и получить ответ через бота
- пользоваться ботом на русском, казахском или английском. язык берётся из настроек Telegram, сменить его можно в меню

## что умеет владелец

админов задают их id в Telegram в конфиге. бот пишет им о каждой новой, перенесённой и отменённой записи.

| команда | что делает |
| --- | --- |
| `/today`, `/tomorrow` | расписание на день по мастерам. нажмите на запись, чтобы отменить её или отметить неявку |
| `/week` | ближайшие 7 дней |
| `/add` | записать клиента, который позвонил по телефону |
| `/block` | закрыть мастеру день или промежуток времени |
| `/blocks` | закрытое время, нажмите, чтобы открыть |
| `/export [дни]` | CSV с записями за последние 30 дней (или указанное число дней) и будущими |
| `/stats` | визиты, отмены, неявки и выручка за 7 и 30 дней |

чтобы ответить клиенту, ответьте на его сообщение в чате с ботом.

## правила записи

правила задаются в `business.toml`, в разделе `[rules]`:

| ключ | по умолчанию | что значит |
| --- | --- | --- |
| `slot_minutes` | 30 | шаг между началами слотов |
| `min_lead_minutes` | 60 | за сколько минут до визита клиент ещё может записаться |
| `horizon_days` | 14 | на сколько дней вперёд открыт календарь |
| `cancel_minutes` | 120 | после этого срока перенести или отменить запись может только админ |
| `max_active` | 2 | сколько будущих записей может держать один клиент |
| `remind_hours` | `[24, 2]` | когда слать напоминания |

бот проверяет пересечения и вставляет запись в одной транзакции SQLite. если два клиента нажмут на одно время сразу, запись получит один, а второй увидит «Это время только что заняли».

## установка

нужен Python 3.11 или новее, я проверял на 3.14.

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt
cp deploy/env.example env
cp business.example.toml business.toml
```

1. создайте бота в [@BotFather](https://t.me/BotFather) и впишите его токен в `env`, в `BOT_TOKEN`.
2. впишите свой числовой id в Telegram в `ADMIN_IDS`, несколько id через запятую. id покажет [@userinfobot](https://t.me/userinfobot).
3. опишите бизнес в `business.toml`: услуги с длительностью и ценой, мастеров с рабочими часами и обедом.
4. запустите бота и отправьте ему `/start` с каждого админского аккаунта. первым бот в Telegram написать не может.

```sh
.venv/bin/python -m bookbot
```

бот читает `./env`, файл из `BOOKBOT_ENV` или `~/.config/bookbot/env`. записи он хранит в файле SQLite из `DB_FILE`. после правки `business.toml` перезапустите бота.

в `deploy/` лежат пользовательский юнит systemd и обёртка `bookbot on|off|restart|status|logs`. юнит ищет проект в `~/dev/bookbot`.

## тесты

```sh
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest
```

тесты проверяют расчёт слотов, транзакцию записи и целые сценарии в чате. сценарии гоняют настоящие обработчики на поддельной сессии Telegram, токен и сеть для них не нужны.

## устройство

```
bookbot/
  config.py      env и business.toml
  db.py          схема, запросы, транзакция записи
  slots.py       расчёт свободных слотов
  texts.py       строки на трёх языках
  ui.py          клавиатуры, карточки, общие помощники
  reminders.py   цикл напоминаний
  handlers/      обработчики клиента и админа
```
